# G1 — One-page research brief

| Field | Project information |
|---|---|
| **Review topic and key papers** | Token-level uncertainty as a predictor of hallucination in LLMs (Bhagat, literature review, 2026). Original sources re-checked for this study: SelfCheckGPT (Manakul et al., EMNLP 2023, Table 2 and Table 8 numbers verified from arXiv 2303.08896); SAR / TokenSAR (Duan et al., ACL 2024); Semantic entropy (Kuhn et al., ICLR 2023; Farquhar et al., Nature 2024); LM-Polygraph (Vashurin et al., TACL 2025). |
| **Research gap** | (i) The review's Sec. 8.2 proposes *semantic-anchor weighting* (weight tokens that belong to entities/numbers/dates) as a cheap, single-pass alternative to SAR's similarity-model relevance — never tested. (ii) Sec. 8.3 proposes a *two-stage* design (cheap token screen, expensive semantic check only on flagged spans) — the review lists it as untested (Sec. 7). (iii) Sec. 6.4/8.4: token scores depend on the model; SelfCheckGPT Table 8 shows open proxy LMs (LLaMA, OPT, GPT-J, NeoX) are near or below random with Max(−log p) — the black-box/proxy setting where the generator's own log-probs are unavailable is the realistic one for API models. |
| **Research question** | **RQ1** When the generator's log-probabilities are unavailable, how well do token-level uncertainty scores computed by small open *proxy* LMs detect non-factual sentences, and how does this depend on proxy size/family and on the aggregation rule? **RQ2** Does semantic-anchor weighting (entities/numbers only) or SAR relevance weighting improve on the plain average? **RQ3** Can a token-score screen route only a fraction of sentences to SelfCheckGPT-NLI while keeping most of its detection quality? |
| **Study pathway** | **B + C**: controlled comparative study of token-level scores across six proxy LMs, plus one targeted modification (anchor weighting) evaluated against the unmodified baseline and against the published SAR weighting, plus a two-stage hybrid evaluation. |
| **Dataset / protocol** | SelfCheckGPT WikiBio (`potsawee/wiki_bio_gpt3_hallucination`, CC-BY-SA-3.0): 238 passages, 1,908 annotated sentences, 20 GPT-3 samples per passage. Used only as a test set; no training, no tuning. Primary metric AUC-PR (NonFact) with SelfCheckGPT's exact evaluation code path (precision_recall_curve + auc). Passage-level bootstrap (1,000 resamples) for CIs and paired differences. |
| **Baseline / comparators** | (1) Random baseline (must reproduce 72.96 / 29.72 / 27.04). (2) SelfCheckGPT-NLI with the released `potsawee/deberta-v3-large-mnli` (paper: 92.50 AUC-PR) — re-implemented in batched form and checked against the official scoring logic (the package itself does not import under transformers 5). (3) Proxy-LM Avg/Max(−log p), Avg/Max(H) (paper reports these for LLaMA/OPT proxies). (4) SAR relevance weighting (published method). |
| **Primary metric and control** | AUC-PR NonFact (higher = better). Held constant: same 1,908 sentences, same prefix, same tokens per model, fp16, no sampling (deterministic forward passes). |
| **Computing and risks** | Google Colab, 1× Tesla T4 16 GB. Proxy LMs ≤ 3B parameters (7B does not fit in fp16). Risk: proxy scores may be near random (as in the paper) → still a valid negative result. Fallback if NLI model unavailable: report proxy-only study. |
| **First executable milestone** | Done: data download + sentence localisation (1,908/1,908 sentences located; label counts 761/631/516 reproduce the 72.96 % non-factual rate). |
